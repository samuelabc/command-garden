<objective>
Port the journal backend from `dashboard/api/src/journal/` (NestJS) to `commandGarden/app/src/server/journal/` (Fastify). Create a `POST /api/journal/generate` route that returns aggregated data from Git source (via ADO REST API). Other sources (timetracking, meetings, jira) are stubbed to return null gracefully — they depend on connectors built in Phase 2.
</objective>
