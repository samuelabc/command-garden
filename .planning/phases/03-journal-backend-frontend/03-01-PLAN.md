<objective>
Update the journal backend to use all 3 Phase 2 commandGarden connectors (ado/git-commits, outlook/my-meetings, jira/my-tickets) via the daemon API instead of direct REST API calls. All data flows through the daemon — no more PAT-based direct API calls. Add audit logging for each generation.
</objective>

<tasks>

### Task 1: Rewrite GitSource to use ado/git-commits connector

<read_first>
- `commandGarden/app/src/server/journal/sources/git.source.ts`
- `commandGarden/connectors/ado-git-commits.yaml` (connector schema — args and columns)
</read_first>

<action>
Rewrite `commandGarden/app/src/server/journal/sources/git.source.ts`:
- Add `DaemonClient` constructor parameter (same pattern as TimetrackingSource/MeetingsSource)
- Remove all direct REST API calls (`fetch` to `dev.azure.com`)
- Remove `headers()`, `baseUrl()`, `fetchCommitsViaPushes()`, `fetchPushDetail()`, `fetchCompletedPRs()` methods
- Remove `Buffer.from` PAT auth logic
- Replace `fetch()` with single call: `this.daemon.post('/api/run', { connector: 'ado/git-commits', args: { project, repo, fromDate, toDate, author } })`
- Parse daemon response: `result.data` is array of rows matching ado-git-commits.yaml columns
- Map connector rows to `GitData` interface: aggregate daily commits from `date` field, count PRs from `isPR === 'true'` rows, build `repos` array
- Read project/repo config from `journalConfig.azureDevOps.repos` — call connector once per repo, aggregate results
- Wrap in try/catch, return empty `GitData` on failure (graceful degradation)
</action>

<acceptance_criteria>
- `GitSource` constructor takes `DaemonClient`
- No direct `fetch()` calls to `dev.azure.com`
- No `Buffer.from` or PAT auth
- Calls daemon `/api/run` with `connector: 'ado/git-commits'`
- Returns `GitData` with aggregated commits and PRs from all configured repos
- Returns empty GitData on failure (not null — differs from meetings/timetracking)
</acceptance_criteria>

<verify>
```bash
grep "DaemonClient" commandGarden/app/src/server/journal/sources/git.source.ts
grep "ado/git-commits" commandGarden/app/src/server/journal/sources/git.source.ts
grep "Buffer.from" commandGarden/app/src/server/journal/sources/git.source.ts
# Should find DaemonClient and connector name, NOT Buffer.from
```
</verify>
